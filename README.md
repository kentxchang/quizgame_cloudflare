以 Cloudflare 邊緣運算為架構的全端互動教學應用程式，整合**題庫管理**、**AI 智慧出題**、**27 款遊戲化即時派送**、**免帳號自動收卷**與**視覺化學習歷程報表**。專為現代學校教室與數位教學設計，幫助教師在課堂上秒速引起學生學習動機，打造充滿活力的高互動課堂！

## 🌟 平台完整功能特色介紹

### 1. 豐富多元題型與題庫管理
- **六大多元題型支援**：
  - 選擇題（單人闖關／雙人即時對戰）
  - YouTube 影音測驗（邊看影片邊答題，影片連結整合題庫）
  - 閱讀理解測驗（文章文本直接綁定題庫，派送免重複輸入）
  - 配對題（左欄與右欄概念對應）
  - 排序題（事件時間軸、步驟順序排列）
  - 圖片標示題（地圖、人體構造、圖表熱點標註）
- **一題一題視覺化卡片編輯器**：
  - 所有題型在編輯時，告別複雜的逗號程式碼，全面採用直覺的**卡片式獨立編輯介面**。
  - 包含題幹、選項 1~4、正確答案點選單選框、詳細解析說明，可自由增刪題卡與即時預覽。
- **快速分類切換與即時關鍵字查詢**：
  - 題庫管理與任務管理皆內建快捷標籤篩選（選擇題、閱讀、影片、配對、排序、圖片...）與即時搜尋欄，題庫再多也能秒速檢索。

### 2. 多來源 AI 智慧出題助理
- **三大 AI 引擎自由切換**：
  - **Google Gemini**：支援官方最新高速模型（如 `gemini-3-flash-preview`、`gemini-2.5-pro`、`gemini-2.5-flash`），可自訂儲存個人專屬 API Key。
  - **本地 Ollama AI**：支援校園或個人電腦本機執行的開放模型（如 `llama3`、`taiwan-llama`、`deepseek-r1` 等），內網運算不外流，零成本且保障隱私。
  - **macOS 本地 Apple AI**：相容 Apple Silicon 本機神經網路引擎（MLX / Local API），提供離線推論。
- **一鍵自動生成題庫**：只需輸入教學主題、課文段落或單元概念，AI 自動產出符合格式的題目、干擾選項與解析說明。

### 3. 27 款派送遊戲矩陣（遊戲化學習）
所有遊戲皆可一鍵綁定題庫進行派送，涵蓋多種感官與思維訓練機制：
- **雙人即時對戰（同螢幕/雙人搶答）**：
  - 經典貓狗大戰、城堡攻防戰、拔河搶答、太空競速、魚群爭霸、怪獸對抗、防禦箭塔、方格佔領、海盜奪寶、廚神料理、機器人格鬥。
- **單人挑戰與反應闖關**：
  - 四線跑酷、切切樂（水果答題）、迷宮吃豆（**幽靈隨機動態出生，安全距離開局**）、貪吃蛇（**支援無界穿牆，碰撞自身才扣命**）、太空侵略者。
- **思維、記憶與配對整理**：
  - 記憶翻牌、電路接線、彩色氣泡、旋轉壽司、分類垃圾桶、拖曳排序、交換排序、排字過河、圖片熱點標記。
- **深度閱讀與素養理解**：
  - 文章閱讀測驗、YouTube 影音時間戳測驗。

### 4. 任務派送與 QR Code 投影
- **一鍵派送與獨立專屬短網址**：自動生成短網址（`/play/:id`），並提供專屬彈窗顯示超清晰 QR Code，大螢幕投影讓全班學生 3 秒掃描加入。
- **免帳號、無門檻開玩**：學生無需註冊帳號或記住密碼，手機/平板/電腦掃碼輸入「姓名」或「座號」即刻作答。
- **任務狀態隨時管控**：教師可隨時於後台開啟/關閉收件，或依課堂進度歸檔管理。

### 5. 100% 全自動成績送出（Tracker SDK）
- **作答完成自動交卷**：學生完成遊戲後，系統即時透過背景發送完成報告至教師後台，**完全不需要學生手動點擊送出**，徹底解決「忘記按提交」的課堂困擾。
- **閱讀與影片測驗解析保留**：作答完畢自動送出後，畫面停留在詳細解析頁面，學生可自主檢視答題對錯、正確答案與解析說明。
- **再玩一次與獨立作答歷程**：學生點擊「再玩一次」將自動產生新的嘗試序號（Attempt ID），鼓勵反覆精熟學習，系統完整記錄每次挑戰成果。

### 6. 多平台試算表匯出支援
- **選擇題 4 大平台匯出格式**：一鍵將題庫匯出為相容 Wayground、Kahoot、Wordwall 以及繁體中文標準書商格式之 Excel 試算表（`.xlsx`）。
- **配對題雙欄互換 Excel 匯出**：
  - **正向配對 (左欄 ➔ 右欄)**：A 欄題目/詞彙，B 欄配對/解釋。
  - **反向配對 (右欄 ➔ 左欄)**：二欄互換，A 欄解釋/答案，B 欄題目/詞彙。便於轉移至其他教學軟體。

### 7. 教師後台數據分析與 CSV 匯出
- **全班學習概況圖表**：成績分佈長條圖、全班平均分、最高分、答對率與平均耗時統計。
- **逐題作答診斷紀錄**：點開任一學生可檢視逐題作答選擇、正確答案、是否答對及作答時間戳記，輕鬆找出迷思概念。
- **一鍵匯出 CSV 報表**：支援下載標準 CSV 試算表，便於登錄學期成績與檔案彙整。

## 🏫 教室課堂多元應用指南 (教學情境實務)

### 情境 1：課前 3 分鐘引起動機與複習暖身（Warm-up）
- **操作方式**：上課鐘響時，教師將「經典貓狗大戰」或「切切樂」任務 QR Code 投影在大螢幕上。
- **教學效益**：學生一進教室立刻掃碼開始快節奏答題，3 分鐘內喚醒上週課程記憶，迅速集中全班注意力，營造熱絡的學習氛圍。

### 情境 2：課中雙人生生互動與同儕學習（Peer Collaboration）
- **操作方式**：課堂進行到概念檢核時，讓鄰座兩位同學共用一臺平板，派送「城堡攻防戰」或「拔河搶答」。
- **教學效益**：兩位學生必須思考正確答案才能攻擊或防禦，促成彼此間的討論、辯證與同儕互助，大幅提升低成就學生的參與意願。

### 情境 3：語文與雙語單字精熟（Drill & Practice）
- **操作方式**：英語單字課或國語成語課時，利用「配對題」派送「記憶翻牌」或「旋轉壽司」，並可使用反向匯出功能製作雙向練習題。
- **教學效益**：將死記硬背轉化為視覺與記憶遊戲，學生在挑戰破關的過程中自發性地反覆練習，達成單字音義的深層精熟。

### 情境 4：跨領域素養導向與多文本閱讀（Reading Literacy）
- **操作方式**：社會、自然或國語課堂中，教師利用「閱讀理解測驗」或「YouTube 影片測驗」派送時事短文或科普解說影片。
- **教學效益**：學生先閱讀長文或觀看精選影片，接著回答深層思考題。答完後系統**自動交卷**並停留在解析頁面，學生可對照原文與解析自我訂正，培養自主閱讀素養。

### 情境 5：課堂即時診斷與精準補救（Formative Assessment）
- **操作方式**：下課前 5 分鐘進行課堂總結性評量，全班完成遊戲後，教師在電子白板打開「教師數據後台」。
- **教學效益**：透過成績分佈圖與逐題錯誤統計，教師能當場發現「哪一題全班答錯率最高」，立即針對該盲點重點講解 2 分鐘，實現免改考卷、即時診斷、精準教學！

## 🚀 部署到 Cloudflare Workers（最推薦，零伺服器維護）

### 步驟 1：在專案資料夾打開命令視窗
1. 用檔案總管打開 `quiz-game-platform` 資料夾（看得到 `wrangler.jsonc` 的那一層）。
2. 在檔案總管上方的**網址列**輸入 `cmd` 後按 Enter，即可開啟命令提示字元。

### 步驟 2：登入 Cloudflare 帳號
輸入：
```bash
npx wrangler login
```
- 若出現安裝詢問，輸入 `y` 按 Enter。
- 瀏覽器會自動彈出 Cloudflare 授權網頁，點擊 **Allow（允許）** 即可。

### 步驟 3：一鍵部署上線
輸入：
```bash
npx wrangler deploy
```
- 第一次使用會引導設定個人的 `workers.dev` 子網域。
- 部署成功後即會輸出專屬線上網址：
  ```text
  https://quiz-game-platform.[你的子網域].workers.dev
  ```

### 步驟 4：資料庫自動就緒
本系統採用 Cloudflare Workers 免費方案專屬的 `new_sqlite_classes` Durable Objects SQLite 規格。在執行 `wrangler deploy` 時，Cloudflare 會**全自動建立內建 SQLite 資料庫與關聯繫結**，無需手動建立資料庫或設定連接字串。

## 🛠️ 本地開發與除錯

若需在個人電腦本機預覽或開發測試：

```bash
# 安裝相依套件
npm install

# 啟動本地開發伺服器
npx wrangler dev
```

開啟瀏覽器前往終端機顯示的本地網址（預設為 `http://localhost:8787`），即可進行功能測試。

```text
quiz-game-platform/
├── wrangler.jsonc             # Cloudflare 部署設定檔 (使用 new_sqlite_classes Durable Objects)
├── package.json               # 專案依賴與指令配置
├── tsconfig.json              # TypeScript 編譯組態
├── README.md                  # 平台功能與教學應用說明文件
├── src/
│   ├── index.ts               # Workers 路由分發、/play/:id 動態渲染與 Tracker SDK 自動注入
│   └── durable_object.ts      # Durable Object SQLite 儲存後端、身分驗證、題庫與成績 API
└── public/
    ├── index.html             # 教師管理後台首頁 (Tailwind CSS、Noto Sans TC、圖表視覺化)
    ├── app.js                 # 教師後台前端邏輯 (一題一題編輯、AI 出題、成績統計、Excel 匯出)
    ├── tracker.js             # 學生端即時監控 SDK (自動彈窗、免手動自動交卷、逐題歷程回報)
    ├── qrcode.min.js          # 離線快速 QR Code 生成函式庫
    ├── editor/
    │   └── image-editor.html  # 圖片標示題庫熱點標註編輯器
    └── games/                 # 27 款互動遊戲模板
        ├── two_classic.html   # 貓狗大戰 (經典)
        ├── two_castle.html    # 城堡攻防戰
        ├── two_tug.html       # 拔河搶答
        ├── one_runner.html    # 四線跑酷
        ├── one_maze.html      # 迷宮吃豆 (隨機出生、安全距離)
        ├── one_snake.html     # 貪吃蛇 (無界穿牆、防碰撞自身)
        ├── one_reading.html   # 閱讀理解測驗 (文字整合、自動交卷保留解析)
        ├── one_ytquiz.html    # YouTube 影片測驗 (影音時間戳)
        ├── match_memory.html  # 記憶翻牌
        ├── sort_drag.html     # 拖曳排序
        ├── image_label.html   # 圖片熱點標示
        └── ... (共 27 款遊戲模板)
```
